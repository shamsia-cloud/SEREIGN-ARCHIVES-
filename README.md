# Luminary Archives

**A Digital Archive of Books Worth Reading.**

A coursework marketplace e-commerce application in the **Books** niche. Buyers browse, search, read free titles, cart premium titles, check out (simulated payment), and open what they own. An administrator manages the catalogue and sees orders.

This repository is the gateway the assignment asked for: source, report, screenshots, and the Python that holds the vital functions. GitHub stores that work. GitHub does not execute Python, and it does not open a shop window, so the living archive is the web application linked from this repo.

## The idea

The book is not merely a product. It is a container of ideas. The software therefore treats four steps as one experience:

**Discovery → Understanding → Acquisition → Access**

*Luminary* means a source of light. The archive is a place those lights can live. **SEREIGN** is the outer name for that house of collections; **Luminary Archives** is the room that was actually built.
